# Practica-4---Sistemas-Embebidos
Comunicación bidireccional UART entre FPGA DE10-Lite y computadora usando MATLAB y ESP32
Esta práctica de laboratorio consiste en diseñar e implementar un sistema de comunicación serial bidireccional entre una computadora y una tarjeta FPGA DE10-Lite utilizando el protocolo UART a una velocidad de 9600 baudios. Para lograr el enlace, un módulo ESP32 se programa en Arduino IDE para actuar como un puente transparente entre el puerto USB de la computadora y la interfaz UART de la FPGA, aprovechando que ambos dispositivos operan con niveles lógicos compatibles de 3.3 V. Desde scripts en MATLAB se envían datos de entrada (la base entre 0 y 255, y el exponente entre 0 y 15) en tramas de bytes consecutivos; la FPGA recibe la información con su módulo receptor (uart_rx), procesa matemáticamente la ecuación $Resultado = \frac{Base^{Exponente}}{2}$ en sus módulos internos y regresa la respuesta a través de su módulo transmisor (uart_tx) hacia el ESP32, permitiendo validar experimentalmente en la consola de MATLAB la correcta recepción y procesamiento del sistema.
