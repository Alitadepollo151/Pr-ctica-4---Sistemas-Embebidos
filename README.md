# Practica-4---Sistemas-Embebidos
Esta práctica de laboratorio consiste en diseñar e implementar un sistema de comunicación serial bidireccional entre una computadora y una tarjeta FPGA DE10-Lite utilizando el protocolo UART a 9600 baudios. Un módulo ESP32 se programa en Arduino IDE para actuar como un puente transparente entre el puerto USB de la PC y la FPGA, garantizando la compatibilidad de voltajes a 3.3 V. Desde MATLAB se envían por UART la base (entre 0 y 255) y el exponente fraccionario $1/2^n$; la FPGA recibe estos datos con su módulo uart_rx, calcula la raíz correspondiente (por ejemplo, $9^{1/2} = \sqrt{9} = 3$) y devuelve el resultado a través de su módulo uart_tx hacia el ESP32 para visualizarlo y validarlo en la consola de MATLAB.
